# Вопросы
1. Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?
2. Можно ли в SVN сделать коммит без интернета? Почему?
3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
# Ответы
1.В Git ветка — это просто лёгкая ссылка на коммит, поэтому она создаётся быстро и почти не занимает место. В SVN ветка фактически создаётся как копия каталога в центральном репозитории, поэтому работа с ветками обычно сложнее.

.Нет. В SVN коммит отправляется сразу в центральный репозиторий, поэтому без подключения к серверу сделать полноценный коммит нельзя.

3.SVN может быть удобнее, если:
- нужен один централизованный репозиторий;
- важен простой контроль доступа к отдельным папкам;
- проект использует много больших бинарных файлов;
- в компании уже давно настроена инфраструктура под SVN.
