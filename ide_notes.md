# Что удобно делать в VS Code
1. Удобно просматривать изменения в файлах через встроенный diff.
2. Удобно видеть изменённые файлы и состояние репозитория в панели Source Control.
3. Удобно просматривать историю изменений и авторство строк с помощью GitLens.
# Что удобнее делать в терминале
В терминале удобнее выполнять более сложные и точные Git-команды, например работу с ветками, rebase и просмотр истории с дополнительными параметрами.
