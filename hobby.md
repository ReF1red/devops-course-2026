# Мой пет-проект
Идея: Telegram-бот для подсчета кбжу(ккал; белки; жиры; углеводы) на основе введенной информации о еде.
Стек: Python, aiogram, SQLite.
Цель: научиться работать с Telegram Bot API, хранением данных и базовой автоматизацией.

## Сроки реализации

Базовую версию проекта планируется реализовать в течение одного месяца.
